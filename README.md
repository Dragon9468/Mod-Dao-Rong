# Mod Đảo Rồng - Kỷ Nguyên Thần Long (Zing Me Remake)

Tái hiện hoàn hảo tựa game nuôi rồng, lai tạo giống và chiến đấu theo lượt huyền thoại từng làm mưa làm gió trên mạng xã hội Zing Me của thế hệ 8x, 9x.

Dự án được xây dựng với công nghệ Web hiện đại (HTML5, Canvas 60 FPS, Web Audio API, WebRTC P2P Multiplayer) và hỗ trợ đóng gói thành ứng dụng Desktop Standalone (.exe) cho Windows.

---

## 🌟 Điểm Nổi Bật & Tính Năng Trọng Tâm

1. **Hệ Thống Quần Đảo Thần Long (Floating Islands)**
   - Các hòn đảo lơ lửng giữa biển mây: *Đảo Khởi Nguyên, Đảo Hỏa Diệm Sơn, Đảo Suối Nguồn Pha Lê, Đảo Lôi Vân Phong Bạo, Đảo Băng Cực Bắc, Thánh Địa Hoàng Kim*.
   - Khai phá các hòn đảo mới khi đạt cấp độ yêu cầu.
   - Xây dựng các loại chuồng nuôi theo nguyên tố: *Hỏa Cốc, Thủy Đầm, Thảo Viên, Nham Thạch Đài, Lôi Điện Đàn, Hàn Băng Cung, Thiên Cung Ngũ Hành*.
   - Rồng sinh ra vàng tự động theo thời gian, có bong bóng vàng bay lên để thu hoạch.

2. **Hệ Thống Rồng Đa Dạng & Tiến Hóa 4 Giai Đoạn**
   - Hơn 19 loài rồng biểu tượng: *Hỏa Long, Thủy Long, Thảo Long, Nham Long, Lôi Long, Dung Nham, Bùn Lầy, Hơi Nước, San Hô, Bão Tố, Lôi Hỏa Laser, Băng Tinh, Băng Hỏa, Bạch Long, Dạ Xoa Long, Thần Long Hoàng Kim*.
   - 4 Hình thái phát triển:
     - **Cấp 1 - 3**: Rồng con sơ sinh đáng yêu (Baby).
     - **Cấp 4 - 6**: Niên thiếu (Young) - Bắt đầu tham gia Động Lai Giống.
     - **Cấp 7 - 9**: Trưởng thành (Adult) - Uy dũng, phát quang nguyên tố.
     - **Cấp 10+**: Siêu Cấp Rồng Thần (Titan) - Mở khóa Tuyệt Kỹ Nộ Long tối thượng.

3. **Nông Trại Trồng Trọt & Cho Rồng Ăn (Farming & Feeding)**
   - Gieo trồng 5 loại nông sản: *Dâu Tây Vàng, Ngô Vàng Long Tộc, Quả Gai Đảo Rồng, Táo Thần Bất Tử, Hạt Đậu Thần Bay*.
   - Thu hoạch thức ăn tích trữ vào kho.
   - Cho rồng ăn tăng cấp, gia tăng mạnh mẽ chỉ số Máu (HP), Tấn Công (ATK), Phòng Thủ (DEF) và Tốc Độ (SPD).

4. **Động Lai Giống & Ổ Ấp Trứng (Breeding Sanctuary & Hatchery)**
   - Phối giống 2 chú rồng trưởng thành (Cấp >= 4) để tạo ra các loài rồng lai thế hệ mới.
   - Ổ ấp trứng đếm ngược thời gian, tương tác gõ vỏ trứng để chào đón rồng con ra đời.

5. **Đấu Trường Chiến Đấu Theo Lượt (Turn-based Combat)**
   - Hệ thống tương sinh tương khắc ngũ hành:
     - **Thủy** dập **Hỏa** (+50% sát thương)
     - **Hỏa** thiêu **Mộc** (+50% sát thương)
     - **Mộc** hút kiệt **Thổ** (+50% sát thương)
     - **Thổ** cản **Lôi** (+50% sát thương)
     - **Lôi** giật **Thủy** (+50% sát thương)
     - **Quang** và **Ám** tương khắc kép
   - Viễn chinh 5 chương cốt truyện vượt ải với các Boss Thần Long kịch tính.
   - Thanh Nộ (Rage): Tích lũy khi ra đòn và nhận sát thương để xuất chiêu Nộ Long hủy diệt.

6. **Chơi Cùng Bạn Bè Trực Tuyến (Multiplayer P2P qua WebRTC)**
   - Hoạt động 100% không cần thuê máy chủ riêng!
   - **Tạo phòng (Host)**: Sinh mã phòng 6 ký tự hoặc tạo link chia sẻ trực tiếp.
   - **Vào phòng (Join)**: Kết nối P2P hai máy tính/điện thoại trực tiếp.
   - **Thăm Đảo**: Chiêm ngưỡng dàn rồng của bạn bè, tặng quà vàng & thức ăn hằng ngày.
   - **Lôi Đài PvP Trực Tuyến**: So tài đội hình 3 vs 3 với bạn bè theo thời gian thực!

7. **Sao Lưu Dữ Liệu (Save / Export / Import)**
   - Tự động lưu LocalStorage trên trình duyệt.
   - Hỗ trợ xuất mã sao lưu (Save Code) để chuyển đổi giữa Web và bản Desktop EXE.

## 🚀 Hướng Dẫn Khởi Chạy & Đóng Gói EXE

### 1. Chơi Trực Tiếp Trên Web
Chỉ cần mở file `index.html` trên bất kỳ trình duyệt nào, hoặc truy cập cổng game `https://pgame.dragon9468.com/games/daorong/`.

### 2. Chạy Bản Desktop (Electron)
```bash
# Cài đặt dependencies (lần đầu tiên)
npm install

# Khởi chạy bản Desktop
npm start
# Hoặc click đúp file: Chay_Game_Desktop.bat
```

### 3. Đóng Gói Thành File EXE Cho Windows Trên Máy Này
```bash
# Đóng gói cả bản Cài Đặt (NSIS Setup) và bản Chạy Ngay (Portable .exe)
npm run build:exe
# Hoặc click đúp file: Dong_Goi_EXE.bat
```
Sau khi build xong, file `.exe` sẽ nằm gọn trong thư mục `dist/`.

## 🤖 Tự Động Đóng Gói Trên GitHub Actions (Không Lo Nặng Repo)

Repo đã được cấu hình `.gitignore` chuẩn xác để **không bao giờ đẩy file `.exe` nặng lên Git**.

Thay vào đó, file workflow `.github/workflows/build-exe.yml` sẽ tự động:
1. Chạy trên máy ảo Windows của GitHub.
2. Cài đặt môi trường và build file `.exe`.
3. Tải file `.exe` lên **GitHub Actions Artifacts** hoặc **GitHub Releases** khi bạn tạo tag mới (ví dụ `v1.0.0`).
4. Bạn và bạn bè chỉ việc vào mục Releases trên GitHub để tải file `.exe` về chơi mà không tốn dung lượng repo!

### Sao Lưu Lên GitHub Bằng 1-Click:
Click đúp file `Auto_Backup_GitHub.bat` để tự động add, commit và push lên repository `Mod-Dao-Rong` trên tài khoản `Dragon9468`.
